Этот каталog (`черновики/`) содержит всё необходимое, чтобы продолжить работу
над проектом в новом чате без потери контекста.

## Что за проект

Личный планировщик покупок и домашних дел на период **июль 2026 – январь 2027**
с учётом двух ресурсов — **деньги** и **время** (часы). Ведётся по месяцам.

- **Владелец данных:** пользователь (аккаунт GitHub `kvitkoas-sudo`).
- **Онлайн-страница:** https://kvitkoas-sudo.github.io/dela-images/ (GitHub Pages).

## Как всё устроено (архитектура)

Единый источник данных — **CSV в GitHub-репозитории `kvitkoas-sudo/dela-images`**.
Notion больше НЕ используется (осталась как есть, но не ведётся).

```
repo kvitkoas-sudo/dela-images
├── index.html            ← сама страница (GitHub Pages раздаёт её как сайт)
├── data/
│   ├── dela_notion.csv   ← ЗАДАЧИ (главный файл)
│   └── Resursy.csv       ← справочник ресурсов по месяцам (сейчас почти не влияет)
├── ochki/                ← картинки к задачам (пример: фото очков)
└── черновики/            ← этот каталог (handoff)
```

Рабочий цикл: правки вносятся в `data/dela_notion.csv` напрямую через ассистента
(Claude) → заливаются в GitHub → страница подтягивает свежие данные при
перезагрузке (в fetch добавлен антикэш `?t=`). Картинки хранятся в репозитории,
в CSV лежат прямые raw-ссылки (колонка «Фото», несколько ссылок через `|`).

## Структура CSV задач (`data/dela_notion.csv`)

Кодировка **utf-8-sig**, переводы строк **CRLF**. Колонки по порядку:

`Задача, Категория, Статус, Месяц, Приоритет, Комментарий, Сумма,
Трудоёмкость, ч., Дедлайн, Старт, Финиш, Фото`

- **Статус:** `Не выполнено` | `Выполнено` | `Отменено`.
- **Сумма:** отрицательная = трата, положительная = доход, 0 = без денег.
- **Месяц:** формат вида `Август 26`, `Январь 27`.
- **Даты** (Дедлайн/Старт/Финиш): ISO `YYYY-MM-DD`.
- **Фото:** прямые ссылки `raw.githubusercontent.com/...`, несколько — через `|`.

## Страница (index.html) — что умеет

- Вкладки: **Список**, **Гант**, **Ресурсы**.
- Разрезы списка: Месяц / Приоритет / Категория / Тип действия.
  - Приоритет: Высокий → Средний → Низкий; Категория: алфавит; Тип: Купить → Сделать → Продать.
- Переключатель **«Выполненные»** — по умолчанию **выключен**; влияет и на Список, и на Гант.
- Выполненные показываются приглушённо, внутри своих групп (в конце).
- **Фото:** иконка 📷 у задач с фото (Список и Гант), по клику — лайтбокс с листанием.
- **Вкладка «Ресурсы»** считается из задач и разбита на две области:
  - 💰 Деньги: **План / Факт / Остаток** (план = все траты месяца; факт = выполненные; остаток = план − факт).
  - 🕐 Время: **План / Факт / Остаток** (аналогично по часам).
  - «Расход факт» = сумма отрицательных сумм ТОЛЬКО выполненных задач; внемесячные траты игнорируются.

## Как продолжить в новом чате

1. Убедиться, что доступен GitHub-токен (в проекте claude.ai лежит файл
   с токеном; он fine-grained, с правом **Contents: Read/Write** на `dela-images`).
   Если истёк — выпустить новый и, при желании, отозвать старый.
2. Для правок задач: прочитать `data/dela_notion.csv` из GitHub, поменять нужные
   строки, залить обратно (см. `github_csv_helper.py`).
3. Для изменений интерфейса: править локально `index.html` (он же `dela.html`),
   проверять синтаксис JS, заливать как `index.html` (публикация на Pages).
4. Картинки: заливать в репозиторий (напр. в папку по теме), прямые raw-ссылки
   класть в колонку «Фото» нужной задачи (несколько — через `|`).
