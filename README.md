# dela-images — память проекта «Мои дела»

Репозиторий-хранилище проекта: данные личного планировщика «Мои дела» и база знаний
(документация, обработанные источники, черновики). Одновременно служит памятью
между сессиями ассистента.

- **Онлайн-страница планировщика:** https://kvitkoas-sudo.github.io/dela-images/ (GitHub Pages)
- **Владелец:** аккаунт GitHub `kvitkoas-sudo`

## Навигатор по репозиторию

Читай этот файл первым — он даёт точечный доступ к нужным каталогам без полного клонирования.

| Каталог / файл | Что внутри |
|---|---|
| `index.html` | Страница планировщика (раздаётся GitHub Pages как сайт). |
| `data/` | Данные планировщика: `dela_notion.csv` (задачи), `Resursy.csv` (ресурсы по месяцам). |
| `ochki/` | Картинки к задачам (напр. фото очков, статус заказа). |
| `документы/` | Техническая и организационная документация. См. `документы/README.md`. |
| `загрузки/` | Загруженные необработанные источники до конвертации в `.md`. См. `загрузки/README.md`. |
| `черновики/` | Значимые промежуточные результаты и handoff для продолжения работы. См. `черновики/README.md`. |
| `.obsidian/` | Служебные настройки хранилища Obsidian (не редактируется вручную). |

## Тематические кластеры

- **Планировщик «Мои дела»** — `index.html`, `data/`, `ochki/`, handoff в `черновики/`.
  Единый источник данных — CSV в этом репозитории; Notion больше не ведётся.
- **Масло / жидкости Hyundai** — материалы в `документы/`: таблица рекомендованных
  жидкостей Tucson NX4, официальные поставщики XTeer, разбор чата группы Hyundai.

## Правила ведения памяти

Память ведётся скиллом `project-memory`:
- Сохраняем **результат, а не процесс**.
- У каждого каталога свой `README.md` с таблицей содержимого (колонки `Файл`,
  `Что внутри`, `Загружен`, `Изменён`) и блоком `AUTO-LINKS`.
- PAT передаётся только через HTTP-заголовок, никогда в URL.
- Чтение — точечное по этому навигатору; клонирование — только для публикации.
