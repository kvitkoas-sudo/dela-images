## ✅ Кратко: что лить в двигатель

| Параметр | Значение |
|---|---|
| Вязкость | **SAE 0W-20** |
| Допуск | **API SP / ILSAC GF-6** (или новее — **SQ / GF-7**, они обратно совместимы) |
| Объём под замену (слив + заправка) | **≈ 4,8 л** → канистры 4 л не хватает, берите **4 л + 1 л** |
| ❌ Не подходит | Допуск **A5/B5** (это для старых атмосферников, хотя в сервисах иногда советуют) |

«Оригинал Hyundai» = именно бренд **Hyundai XTeer**. Отдельного масла с логотипом просто «Hyundai» у концерна нет.

## 💬 Обсуждение владельцев (Telegram-чат «Масло», Hyundai 1.5 T-GDi) — самари

**Главный спор:** лить **0W-20** (по мануалу) или **5W-30** (по опыту «бывалых»).

- **Опрос «что уже залил»:** 0W-20 — **65%** (166), 5W-30 — 26% (67), 5W-40 — 2% (5), другое — 7% (19).
- **Допуск A5/B5 не подходит** — это для старых моторов; для турбо нужен минимум **ILSAC GF-6 / API SP**.
- В Китае на заводе/сервисе лили и 5W-30 (Castrol), и 0W-20 — единого мнения нет даже там; по книжке — **0W-20**.
- Сторонники 5W-30 (напр. POLYMERIUM XPRO2 5W-30 GF-6A SP) мотивируют непосредственным впрыском и разжижением масла бензином.
- Популярный бюджетный выбор — **MIRAX 0W-20 (SP, GF-6A)** с Ozon/WB (~1056–1873 ₽), есть лаб. тест на oil-club; меняют каждые ~5000 км, довольны.
- Другие названные: Shell Helix Ultra, Sintek 0W-20, Castrol.
- **Общий вывод:** масла есть на любой кошелёк — **главное соблюдать указанные допуски**.

**Робот (DCT):**
- По руководству — «нет необходимости в осмотре или ТО». Но по факту в РФ при вскрытии — масло чёрное, недолив ~0,5 л (в сухой робот входит ~1,7 л).
- Рекомендация участников: **обслужить по приезду машины**, слить/залить по желанию.
- Названо масло: **MTF DCTF 70W (04300KX1B0) Hyundai/Kia** (~1,35к ₽).

**Где покупали (упомянуто):** Автодок, Питеройл, Ozon, Wildberries.
