# Carlinkit X2CA — совместимость с Hyundai Tucson NX4

- **Модель:** Carlinkit X2CA
- **Партномер:** X2CA-OVA-BW-C
- **Подключение:** USB-порт штатной магнитолы, телефон коннектится к адаптеру по Wi-Fi (2.4G + 5G).
- **Bluetooth:** да · Гарантия: 1 год · Страна: Китай
- **Ozon:** артикул 1862904414, рейтинг 4.3 (148 отзывов), цена ~4 339 ₽ (с картой банка).

## Как работает
Адаптер вставляется в USB-порт (с иконкой смартфона / CarPlay), «притворяется» подключённым по кабелю телефоном, а реальный телефон подключается к нему по Wi-Fi. Превращает **проводной** CarPlay в **беспроводной**.

## Подойдёт ли для Tucson NX4
**Да — при условии, что в машине есть штатный ПРОВОДНОЙ Apple CarPlay / Android Auto.**

Проверить:
- **Есть проводной CarPlay** (телефон по кабелю даёт интерфейс CarPlay) → адаптер работает. На NX4 (2021+) проводной CarPlay есть в большинстве комплектаций с экраном 8" и 10.25".
- **Уже штатно беспроводной CarPlay** (топовые комплектации) → адаптер НЕ нужен.
- **CarPlay нет вообще** (базовые комплектации) → адаптер НЕ поможет: он не добавляет CarPlay, только делает существующий беспроводным.

## Нюансы

- Рейтинг 4.3 — нормально для класса, но не идеально.

## Итог
Если на Tucson NX4 есть проводной CarPlay — брать можно, подойдёт. Если сомнения — уточнить по году и комплектации.
