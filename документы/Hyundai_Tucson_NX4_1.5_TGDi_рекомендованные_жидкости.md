## Ключевое по моторному маслу

- Требуемая вязкость: **SAE 0W-20**.
- Допуски: **API SN PLUS / SP** или **ILSAC GF-6**.
- Объём при замене (слив и заправка): **4,8 л**.

### Совместимость купленного масла MIRAX 0W-20 API SQ, ILSAC GF-7A

- Вязкость 0W-20 — совпадает с требованием.
- API SQ новее, чем требуемый SP; ILSAC GF-7A новее, чем требуемый GF-6. Более новые категории обратно совместимы.
- **Вывод:** MIRAX 0W-20 GF-7A / API SQ **соответствует требованиям и перекрывает их** — допустимо к применению.
- При замене ориентироваться на объём **≈4,8 л**.

## Примечания

- Для полного привода (4WD) отдельно обслуживаются раздатка и задний редуктор — не забыть при ТО.
- Тип двигателя в таблице — 1.5 T-GDi; на ряде рынков этот же мотор маркируется как 1.6 T-GDi. Сверяться с VIN/руководством конкретного авто.
