# Чат «Масло» — группа Hyundai (Telegram)

> Собрано из HTML-выгрузки Telegram-чата. Дата сборки: 31.08.2026.
> Период переписки: 23–28 мая 2025. Сообщений: 83 (из них 13 с фото, 1 опрос).
> Тема группы: какое моторное масло лить в Hyundai (двигатель Smartstream **1.5 T-GDi**, Tucson и др.), плюс масло в робот (DCT).

## Краткая суть обсуждения

**Главный спор:** лить **0W-20** (как по инструкции/мануалу производителя) или **5W-30** (по опыту «бывалых»).

Результаты опроса «Какое масло уже залил(а)»: **0W-20 — 65% (166)**, 5W-30 — 26% (67), 5W-40 — 2% (5), другое — 7% (19).

Ключевые тезисы участников:
- **Допуск A5/B5 — не подходит** для этого мотора (Женя: это спецификация для старых двигателей). Для турбомоторов нужен минимум **ILSAC GF-6 / API SP**.
- Николаю в сервисе советовали A5/B5 — в чате отговорили.
- В Китае на заводе/сервисе заливали как **5W-30** (Castrol), так и **0W-20** — единого мнения даже у китайцев нет. По мануалу (книжке) — **0W-20**.
- Дмитрий после изучения обзоров выбрал **5W-30 SP GF-6** (POLYMERIUM XPRO2 5W-30 GF-6A SP), мотивируя непосредственным впрыском и разжижением бензином.
- Популярный бюджетный выбор — **MIRAX 0W-20 (API SP, ILSAC GF-6A)** с Ozon/WB (~1056–1873 ₽), есть лабораторный тест на oil-club; многие льют повторно, довольны, меняют каждые ~5000 км.
- Другие названные масла: **Shell Helix Ultra**, **Sintek 0W-20**, **Castrol**, а также аналог Sintek с тем же заводом-изготовителем.
- **Общий вывод (Анатолий):** на любой кошелёк есть масла — главное соблюдать указанные **допуски**.

**Масло в робот (DCT):**
- По руководству РКПП: «нет необходимости в осмотре или ТО». Но по факту при вскрытии в РФ — масло чёрное, недоливы ~0,5 л (в сухой робот входит ~1,7 л).
- Рекомендация участников: обслужить по приезду машины, слить/залить по желанию.
- Названо масло: **MTF DCTF 70W (04300KX1B0) HYUNDAI/KIA** (WB), цена на робот упала с 1,9к до 1,35к; допуск раздатки/редуктора обсуждался отдельно.

**Где купить (упомянуто):** Автодок, Питеройл (все масла), Ozon, Wildberries.
